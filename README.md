# InnovationAdoption

- Agent-based model of innovation adoption
- Different agent types with different attributes are the agents of the model
- Out of the 4 different agents, ratio of managers and people open to change are considered as inputs
- The number of policy makers is set to one and ratio of people less willing to adopt depends on the ratio of other agents
- Each agent is influenced by its neighbours
